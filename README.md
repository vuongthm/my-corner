# Góc nhỏ

Module lưu danh sách nhạc, lời LRC và ghi chép về sách, phim, podcast. Website đọc manifest `module.json`, dữ liệu nhạc ở `music/tracks.json` và các file Markdown theo nhóm/ngôn ngữ.

- `music/`: danh sách, bìa và lời.
- `books/`, `films/`, `podcasts/`: các ghi chép và bản dịch.

Xem [CONTRIBUTING.md](CONTRIBUTING.md) để thêm hoặc sửa nội dung.
